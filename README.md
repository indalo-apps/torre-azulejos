# Torre de Azulejos

© 2026 **Adela Moreno Vega** y **Carlos Moreno Otto**. Todos los derechos reservados (ver [LICENSE](LICENSE)).

Juego de un solo toque para el móvil: los azulejos van y vienen y hay que soltarlos encima de la torre. Lo que sobresale se corta; si aciertas justo, ganas un «¡Perfecto!» y, con la racha, el azulejo vuelve a crecer. Tiene récord, mejor racha y un reto del día con racha de días.

Se publica con GitHub Pages: https://indalo-apps.github.io/torre-azulejos/

Enlace para instalarla en el móvil: https://indalo-apps.github.io/torre-azulejos/?instalar

Para sacar una versión nueva: subir el número en `<meta name="app-version">` (index.html) y en `CACHE` (sw.js), y añadir sus novedades en `NOVEDADES`. Los móviles que la tengan abierta se actualizan solos, sin cortar una partida a medias.

## Privacidad
No recoge ningún dato personal: sin cuentas, anuncios, compras, estadísticas ni rastreo. Los récords y ajustes se guardan solo en el móvil.
